# Diary Doodle Studio

사진을 선택해 미리 보고, 정해진 다이어리 낙서 캐릭터 프롬프트를 복사한 다음 ChatGPT에서 사진과 함께 사용할 수 있는 간단한 한국어 웹 페이지입니다.

## GitHub Pages 공개하기
1. 저장소의 **Settings** 탭을 여세요.
2. 왼쪽 메뉴에서 **Pages**를 선택하세요.
3. **Build and deployment**에서 Source를 **Deploy from a branch**로 선택하세요.
4. Branch를 **main**, 폴더를 **/(root)** 로 설정하고 **Save**를 누르세요.
5. 잠시 기다리면 Pages 화면에 공개 주소가 나타납니다. 보통 주소는 `https://pwj7783-coder.github.io/Stickers/` 형태입니다.

## 참고
- 이 페이지는 사진을 서버로 업로드하지 않습니다. 미리보기는 브라우저 안에서만 표시됩니다.
- 실제 이미지 생성은 페이지에서 자동 실행되지 않습니다. 사용자가 사진을 ChatGPT에 직접 첨부하고 프롬프트를 붙여 넣어야 합니다.
- 이미지 생성 기능과 사용량은 ChatGPT 계정/플랜에 따라 달라질 수 있습니다.
